Advanced configuration

Only fill these in if your Amazon account has two-step verification (2SV) enabled. Pick one of the two options below.

Option 1 — One-time code

Enter the 6-digit code from your authenticator app or text message right before clicking Download my data. The code expires fast, so type it last.

Option 2 — TOTP secret key (recommended)

Paste your TOTP "secret key" (also called "seed") once and Marchant will solve MFA automatically on every run — no typing codes. You get this key when you first set up two-step verification on Amazon: Account → Login & security → Two-Step Verification → Authenticator App → "Can't scan the barcode?" reveals a string like JBSWY3DPEHPK3PXP… — that's the key. If you already finished setup, you can re-run the setup wizard to see it again.
